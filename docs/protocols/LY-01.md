# LY-01 — Integridad de capas e historial

**Prioridad:** crítica · **Pruebas:** `tests/Trazo.Rendering.Tests/LY01_LayerIntegrityTests.cs`

## Objetivo

Que ninguna operación sobre una capa altere otras capas o recursos sin motivo, y que deshacer y rehacer devuelvan estados exactos.

## Procedimiento

Sobre un documento real (motor de Direct2D en WARP) se aplican 16 operaciones:

pintar capa 1 → nueva capa → pintar capa 2 → opacidad → modo multiplicar → duplicar → máscara de recorte → ocultar → mostrar → mover capa → combinar abajo → rellenar → invertir → voltear lienzo → color de fondo → eliminar capa.

Después de cada operación se toma una **instantánea**:

- estructura (id, nombre, opacidad, modo, visibilidad, bloqueo alfa, recorte, fondo e índice activo);
- SHA-256 de los píxeles de cada capa;
- SHA-256 de la imagen compuesta.

Luego se deshace todo, comparando cada estado intermedio, y se rehace todo. Por último, el documento se guarda, se cierra y se vuelve a abrir.

## Criterios de aceptación y resultado

| Criterio | Resultado (2026-10-24) |
|---|---|
| Cada operación registra exactamente un paso de historial | ✅ Tras corregir un error: "ocultar" y "mostrar" se fusionaban en un paso |
| El índice de capa activa es siempre válido | ✅ |
| Deshacer restaura cada estado previo con igualdad exacta (hash) | ✅ |
| Rehacer reproduce el estado final exacto | ✅ |
| Guardar y reabrir conserva la estructura; píxeles ± 1 nivel | ✅ La diferencia de 1 nivel proviene de PNG sin premultiplicar en píxeles casi transparentes |
